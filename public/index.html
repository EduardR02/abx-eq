How to interpret

BT Score (Bradley-Terry): A strength rating computed from all your pairwise preferences. Higher means preferred more often. Unlike ELO, this is not affected by matchup order.

Why fewer matchups can work: Bradley-Terry shares information across the full comparison graph, so each choice helps refine multiple relative strengths through transitivity.

p-value (head-to-head table): The probability of seeing this result by chance. Highlighted values under 0.05 indicate statistically significant preference.

ELO: A secondary rating system. Useful as a cross-reference, but can be somewhat order dependent.

Confidence tip: If rankings still feel unstable, run more total matchups to improve convergence.
